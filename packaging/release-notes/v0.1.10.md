## VieNeuTTS v0.1.10 — Windows Release Pipeline Repair

This patch release repairs the Windows validation failure that prevented
v0.1.9 from publishing its release artifacts.

### Fixed

- **Reliable temporary WAV cleanup on Windows:** export cleanup now retries
  transient `PermissionError` failures, which occur when Windows briefly
  retains a file handle after a write failure.
- **Accurate atomic-export regression test:** the test now raises from
  `SoundFile.write()` inside its context manager, so it verifies real cleanup
  after the writer closes instead of leaking the test-owned file handle.

### Verification

- Focused atomic-export cleanup regression test passes.
- `ruff check .`, `ruff format --check .`, and the Release test command all
  pass locally (929 tests).
