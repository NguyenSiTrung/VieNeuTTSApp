## 🚀 VieNeuTTS v0.1.5 — Reading Speed, Voice Audition & Windows Stability

A feature and stability release for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop workstation powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio synthesis run 100% locally on your machine — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **⏱️ Configurable Reading Speed & Pause Duration (WSOLA)**
  - Adjust speech rate from **0.5× to 2.0×** with natural pitch preservation powered by high-fidelity WSOLA (Waveform Similarity Overlap-Add) using pure NumPy.
  - Fine-tune inter-sentence and paragraph pause length from **0.0s to 2.0s** (`silence_p`).
  - Available in the Settings tab with live reset controls and instant audio synthesis feedback.

- **🎧 Voice Preset Audition & Redesigned Voice Picker**
  - Listen to any preset voice immediately with a single click (`auditionVoice`) without altering or clearing the text in your editor.
  - Redesigned VoicePicker modal with regional filtering (**Bắc / Trung / Nam**), gender and style badges, and responsive search.

- **🪟 Windows WASAPI Audio Stability & Crash Prevention**
  - Fixed a critical native `0xC0000005 Access Violation` crash on Windows during long text synthesis when live audio preview was enabled.
  - Eliminated the WASAPI COM audio device "restart storm" during CPU synthesis underruns:
    - Enforced minimum restart intervals (`MIN_RESTART_INTERVAL_MS = 60 ms`).
    - Added an automatic fallback limit (`MAX_CONSECUTIVE_AUDIO_RESTARTS = 5`) that cleanly turns off live playback and allows synthesis to complete seamlessly to disk.
  - Added robust exception shielding in `TransportIODevice.readData()` to protect against native audio thread exceptions.

- **🔄 Silent Generate-Then-Replay Default (`live_preview = False`)**
  - "Phát trực tiếp" (Live preview) is now **OFF by default**, generating complete, validated 48 kHz WAV files directly to disk and automatically playing back from the start upon completion.
  - Eliminates audio stuttering and buffer underruns on CPU systems.
  - Existing users upgrading from v0.1.3/v0.1.4 automatically adopt the stable default without needing to reset their settings.

- **💡 Long Text Synthesis Guidance & Warnings**
  - Added smart in-app advisory labels in both the Text studio and Paragraph studio when input text exceeds 2,000 characters, alerting users to disable Live Preview or switch to the Audiobook (EPUB) studio.
  - Comprehensive documentation in `README.md` explaining memory management best practices (avoiding unbounded ONNX Runtime CPU memory arena growth by using chaptered synthesis for large books).

### 💡 Notes for First-Time Users

1. **Model Weights (~330 MB, one time)**: not bundled in the installers — the app downloads and verifies the official CPU baseline automatically on first launch. You can also import a verified offline pack (`backbone/` + `codec/`) directly via Settings. After that it runs fully offline.
2. **macOS Gatekeeper**: the build is ad-hoc signed. On **Sequoia/Tahoe**, open the app once, then go to **System Settings → Privacy & Security → Open Anyway**; on **Sonoma and earlier**, right-click `VieNeuTTS.app` → **Open** → **Open**; any version via terminal: `xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app`.
3. **Linux Prerequisites**: `sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0`.
