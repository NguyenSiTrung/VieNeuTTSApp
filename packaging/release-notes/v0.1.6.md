## 🚀 VieNeuTTS v0.1.6 — In-App Update Checks, Platform Downloads & Stability Hardening

A feature and stability release for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop workstation powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio synthesis run 100% locally on your machine — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **🔄 In-App Update Check via GitHub Releases (`core/updates.py`)**
  - **Zero Telemetry / Offline-First**: Queries the official GitHub Releases API (`repos/NguyenSiTrung/VieNeuTTSApp/releases/latest`) using Python's standard library (`urllib`). No third-party analytics, telemetry, or tracking.
  - **Platform-Aware Asset Matching**: Automatically detects the running OS (`windows-x64`, `linux-x64`, `macos-arm64`) and resolves the matching platform release asset with a direct one-click download action.
  - **Settings "Cập nhật ứng dụng" Card**: Dedicated software update card in Settings displaying current version, latest version, and links to release notes. Includes a list of other platform downloads for cross-device needs.
  - **Smart Background Checking & Visual Badge**: Performs a silent update check 3 seconds after application startup and rechecks hourly in the background. Shows an unobtrusive orange dot badge on the Settings navigation item when a new update is available.
  - **Manual Check**: Provides an instant "Kiểm tra cập nhật" button with live status, loading indicator, and friendly network error handling.

- **🏷️ Frozen Build Version Stamping & CLI `--version`**
  - Stamped version tags during release packaging (`release.yml` and `packaging/vienetts-app.spec`) into `src/vienetts_app/_version.py` and macOS `CFBundleShortVersionString`.
  - Added a `--version` flag to the `vienetts-app` CLI to easily inspect the installed binary version from the terminal.
  - Added release-time validation asserting that frozen binaries report the exact tag version.

- **📖 Audiobook Progress Initialization Bugfix**
  - Fixed an unhandled `AttributeError: '_render_progress'` in the QML console when loading an EPUB book.
  - Properly initialized `_render_progress = 0.0` in `AudiobookController.__init__` before the first render is triggered, ensuring seamless property binding.

- **🛡️ CI/CD Runner Hardening & Deadlock Prevention**
  - Bounded benchmark subprocess wait times (240s for performance harness children, 60s for startup iterations with graceful fallback, 900s for matrix runner) to prevent headless runner deadlocks during Qt teardown from stalling release builds.
  - Relaxed slow-sink wall-clock budget (1.0s → 5.0s) to guard against intermittent pipeline stalls on shared CI runners.
  - Synchronized smoke test cancellation triggers directly with inference startup in `tests/smoke/test_e2e_flows.py` to eliminate race conditions.

- **⚡ Test Suite Consolidation & Optimization**
  - Consolidated redundant and micro-split test cases across unit and smoke suites, eliminating artificial sleep delays and reducing execution time while maintaining full test coverage.
  - Formatted all test modules with `ruff` to pass strict CI lint checks.

### 💡 Notes for First-Time Users

1. **Model Weights (~330 MB, one time)**: not bundled in the installers — the app downloads and verifies the official CPU baseline automatically on first launch. You can also import a verified offline pack (`backbone/` + `codec/`) directly via Settings. After that it runs fully offline.
2. **macOS Gatekeeper**: the build is ad-hoc signed. On **Sequoia/Tahoe**, open the app once, then go to **System Settings → Privacy & Security → Open Anyway**; on **Sonoma and earlier**, right-click `VieNeuTTS.app` → **Open** → **Open**; any version via terminal: `xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app`.
3. **Linux Prerequisites**: `sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0`.
