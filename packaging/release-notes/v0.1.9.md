## 🚀 VieNeuTTS v0.1.9 — NVIDIA CUDA Builds for Windows & Linux

A hardware-expansion release for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop workstation powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio synthesis run 100% locally on your machine — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **⚡ NVIDIA CUDA Download Variants (Windows & Linux)**
  - **Two Variants Per Platform**: Every release now ships a lightweight CPU build (ONNX Runtime, torch-free, ~90 MB) *and* a `‑cuda` build that bundles the full PyTorch cu128 stack (`torch` 2.8.0, `torchaudio`, `transformers` 4.57.6, `safetensors`) — no Python installation required on either variant.
  - **Zero-Setup GPU Synthesis**: The CUDA zip runs the PyTorch backend directly on your NVIDIA GPU. Only requirements: an NVIDIA GPU and an up-to-date driver (cu128 runtime). No pip, no venv, no CUDA toolkit install.
  - **Variant-Aware Update Checks (`core/updates.py`)**: The frozen app writes a `_cuda_build` marker into its package at build time; the in-app update check reads it and offers the matching `-cuda` asset. Asset matching checks the `-cuda` suffix *before* the plain keys, so a CUDA user is never offered the CPU zip (or vice versa).
  - **New Release Artifacts**: `VieNeuTTS-<ver>-windows-x64-cuda.zip` and `VieNeuTTS-<ver>-linux-x64-cuda.zip`, built by two new matrix jobs in the release workflow (`VIENETTS_GPU_BUILD=1`, 90-minute budget for the ~3 GB torch collection). CI smoke-tests both variants through the packaged binary (CPU-side; real-GPU synthesis validated manually).
  - **macOS Unchanged**: No CUDA variant for macOS (the pipeline does not support Metal).

- **🎯 Truthful Backend Selection & Honest Error Messages**
  - **Fixed Misleading CUDA Error**: On a CPU-only install, selecting the PyTorch (NVIDIA CUDA) backend previously failed at synthesis with *"Install the GPU extra (pip install 'vienetts-app[gpu]')"* — impossible in a packaged app. Frozen builds now show actionable guidance instead: switch the backend to ONNX in Settings, update the NVIDIA driver if using the CUDA download, or install the CPU version.
  - **`torchAvailable` Property (`ui/controller.py`)**: The controller now exposes an injectable, lazily-evaluated torch/CUDA availability probe (`probe.installed && probe.cuda_available`) to QML. Construction never imports torch (cold-start stays model-free, NFR-2.1).
  - **Non-Blocking Prewarm (`app.py`)**: The probe runs on a daemon thread 110 ms after first paint — same off-thread discipline as the hardware note — so the QML binding never pays the 1–3 s torch import on GPU installs.
  - **Settings Hint (`SettingsTab.qml`)**: Selecting the CUDA backend on a machine without the runtime now shows a muted explanatory hint (fallback to ONNX/CPU; use the CUDA download or switch to ONNX) instead of failing silently at synthesis time.

- **🧪 Test Suite Expansion**
  - 12 new unit tests covering: CUDA asset-key matching and display names, marker-driven `current_platform_key()` behavior (Windows/Linux/macOS), torch availability (present/absent/broken-CUDA/lazy probe), and the frozen-aware error message.
  - Full suite passing with **929 tests**; `ruff check` and `ruff format --check` clean.

### 📦 Platform Downloads & Installation

| Platform | File | Architecture | Notes |
|---|---|---|---|
| **macOS** | `VieNeuTTS-0.1.9-macos-arm64.dmg` | Apple Silicon (M1/M2/M3/M4) | Open `.dmg`, drag to Applications. *(See Gatekeeper note below)* |
| **Windows (CPU)** | `VieNeuTTS-0.1.9-windows-x64.zip` | x64 (Windows 10/11) | Extract zip, double-click `VieNeuTTS/VieNeuTTS.exe` |
| **Windows (CUDA)** | `VieNeuTTS-0.1.9-windows-x64-cuda.zip` | x64 + NVIDIA GPU | Same as above; ~2 GB larger, runs PyTorch on the GPU |
| **Linux (CPU)** | `VieNeuTTS-0.1.9-linux-x64.zip` | x64 (Ubuntu 22.04+ / glibc 2.35+) | Extract zip, run `./VieNeuTTS/VieNeuTTS` — or `sudo ./VieNeuTTS/share/linux/install.sh` for a menu entry |
| **Linux (CUDA)** | `VieNeuTTS-0.1.9-linux-x64-cuda.zip` | x64 + NVIDIA GPU | Same as above; ~2 GB larger, runs PyTorch on the GPU |

**Which variant?** No NVIDIA GPU → take the plain (CPU) zip: smaller and runs the ONNX Runtime engine. NVIDIA GPU with a recent driver → take the `-cuda` zip for faster synthesis. The app remembers which variant you installed and offers the matching file on update checks.

### 💡 Notes for First-Time Users

1. **Model Weights (~330 MB, one time)**: not bundled in the installers — the app downloads and verifies the official CPU baseline automatically on first launch. Model weights are identical for CPU and CUDA variants. You can also import a verified offline pack (`backbone/` + `codec/`) directly via Settings. After that it runs fully offline.
2. **CUDA Driver Requirement**: the `-cuda` builds bundle the cu128 PyTorch runtime — keep your NVIDIA driver current. An outdated driver surfaces as an actionable error with fallback guidance, not a crash.
3. **macOS Gatekeeper**: the build is ad-hoc signed. On **Sequoia/Tahoe**, open the app once, then go to **System Settings → Privacy & Security → Open Anyway**; on **Sonoma and earlier**, right-click `VieNeuTTS.app` → **Open** → **Open**; any version via terminal: `xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app`.
4. **Linux Prerequisites**: `sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0`.
