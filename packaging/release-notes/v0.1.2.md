## 🐛 VieNeuTTS v0.1.2 — Emotion Tags Corrected

A patch release for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop app powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio processing still run 100% locally — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **🎯 Fixed: unsupported emotion tags were spoken out loud**
  The text studio previously offered five inline emotion chips, but the v3 Turbo emotion checkpoint was trained with only **three** non-verbal cues. `[ngập ngừng]` (hesitate) and `[thì thầm]` (whisper) were not among them, so the synthesizer read them as literal words — e.g. *"Tôi [thì thầm]…"* became *"Tôi thì thầm…"* — instead of changing the delivery.
  - The two unsupported chips have been removed from the UI (and the README now lists only what actually works).
  - The supported tags — **`[cười]`** (chuckle), **`[thở dài]`** (sigh), **`[hắng giọng]`** (clear throat) — are unchanged and keep working inline.
  - 💡 **Tip:** for a hesitation-like pause you can still type `…` or `—` directly in the text — punctuation drives the prosody. Whispered delivery isn't possible on this checkpoint; choosing a softer preset voice is the closest alternative.

### 💡 Notes for First-Time Users

1. **Model Weights (~750 MB)**: not bundled in the installers — downloaded automatically from Hugging Face into the local cache on first synthesis.
2. **macOS Gatekeeper**: the build is ad-hoc signed. Right-click `VieNeuTTS.app` → **Open** → **Open**, or run `xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app`.
3. **Linux Prerequisites**: `sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0`.
