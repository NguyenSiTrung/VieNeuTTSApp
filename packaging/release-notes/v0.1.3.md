## 📦 VieNeuTTS v0.1.3 — Guided Model Setup & Reliable Synthesis

A patch release for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop app powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio processing still run 100% locally — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **📦 Guided first-run model setup — no terminal needed**
  The first-launch card no longer tells you to run `python scripts/fetch_models.py`. It now checks the managed official CPU baseline on its own and offers **Download / Cancel / Retry** directly in the UI, with a live progress bar, `Đã lưu X / cần Y` storage readout, and truthful header status (`Sẵn sàng`, `Đang tải mô hình…`, `Đang kiểm tra…`, `Lỗi mô hình`, `Chưa có mô hình`).
  - The **model folder path** is shown in the setup card and the Settings model section, with **copy-path** and **open-folder** buttons.
  - Already have the files? Drop a verified offline pack (`backbone/` + `codec/`) into the shown folder via the **import dialog** and hit Retry — no repository or commands required. (Custom `owner/repo` in Settings still switches to a custom source and disables this flow, as before.)
  - Under the hood the baseline is **pinned** (backbone + codec revisions) and every file is **SHA-256 verified** before an atomic promote; interrupted or corrupt staging is never used, retry **resumes** already-verified files instead of re-downloading, and free space is preflighted (download + 512 MB headroom).
- **🎯 More reliable synthesis under rapid clicks**
  Synthesis events are now routed by **job ID** through a small job queue instead of global listener attachment: stale deliveries from a previous Play are dropped, cancel targets only the job you cancelled, and background audiobook renders no longer flip the text/paragraph status line. The status under the action bar follows your own action (`queued` → `generating`) with its own cancel button.
- **📄 Paragraph studio imports `.srt` subtitles**
  Import `.txt`, `.md`, `.docx`, `.pdf`, **or `.srt`** into the paragraph studio. Subtitles import as **clean spoken text** by default — sequence numbers, ` --> ` timecodes, and `<…>` / `{…}` styling are stripped — with a **Giữ timecode SRT** toggle when you want the verbatim source instead. Files with no timecodes are refused with an explanation rather than being read aloud as numbers.
- **🪟 Fixed: packaged Windows app failed on first synthesis**
  The windowed `.exe` (`console=False`) starts with `sys.stdout`/`sys.stderr` set to `None`, and the download progress writer crashed with `'NoneType' object has no attribute 'write'` — surfaced as `Engine initialization failed` on first synthesis. Stdio is now redirected to devnull at startup (GUI, `--smoke`, and engine init), so the first model download and synthesis work out of the box.
- **🍎 macOS Gatekeeper guide corrected for Sequoia/Tahoe**
  Apple removed the right-click → Open bypass in macOS 15. The README now documents the current flow — open once to register the block, then **System Settings → Privacy & Security → Open Anyway** — alongside the Sonoma-and-earlier path and the `xattr -dr com.apple.quarantine` one-liner.

### 💡 Notes for First-Time Users

1. **Model Weights (~330 MB, one time)**: not bundled in the installers — the app downloads and verifies the official CPU baseline automatically on first launch (see above). After that it runs fully offline.
2. **macOS Gatekeeper**: the build is ad-hoc signed. On **Sequoia/Tahoe**, open the app once, then go to **System Settings → Privacy & Security → Open Anyway**; on **Sonoma and earlier**, right-click `VieNeuTTS.app` → **Open** → **Open**; any version via terminal: `xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app`.
3. **Linux Prerequisites**: `sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0`.
