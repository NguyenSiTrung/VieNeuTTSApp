## 🚀 VieNeuTTS v0.1.8 — Crash Diagnostics, Windows Path Normalization & File Lock Resilience

A stability and hardening release for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop workstation powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio synthesis run 100% locally on your machine — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **🩺 Diagnostic Crash Reporter & Windows Native Dialog (`src/vienetts_app/crash.py`)**
  - **Global Unhandled Exception Hooks**: Installed global `sys.excepthook` and `threading.excepthook` handlers during application bootstrap to intercept unhandled exceptions across main and worker threads.
  - **Diagnostic Crash Logs**: Automatically generates structured, timestamped `crash.log` files in the user data directory (`<UserData>/VieNeuTTS/logs/crash.log`). Log entries capture OS release, architecture, Python runtime, PySide6/Qt versions, GPU status, thread name, exception type, and complete tracebacks.
  - **Windows Native Dialog Fallback**: Packaged GUI applications on Windows run without a console (`console=False`), which previously caused unhandled exceptions to terminate silently. The app now displays a native Windows message box (`ctypes.windll.user32.MessageBoxW`) informing the user and directing them to the diagnostic log file.
  - **GUI Boot Safety Guard**: Wrapped Qt application instantiation in `run_app()` to catch early initialization failures and present an actionable dialog before process exit.
  - **Safe Controller Slot Wrappers**: Protected synthesis and worker startup slots (`_begin_synthesis`, `_ensure_worker`) with structured exception handlers, reporting user-facing error banners via `_set_error` instead of freezing or crashing the GUI on model load errors.

- **🔒 Windows File Lock Resilience & Atomic Update Safeguards**
  - **Retry-Bounded Atomic Replace**: Files accessed by media players, antivirus software, or Windows indexing services can trigger transient `PermissionError` (WinError 32) when overwritten. Added retry loops with bounded exponential backoff on `os.replace` in `IncrementalArtifactWriter`, `save_settings`, and `TTSEngine.persist_voices`.
  - **Zero-Audio-Loss Sibling Fallback**: If the destination file remains locked after retries, `IncrementalArtifactWriter` automatically saves the synthesis result to a timestamped sibling file (`<stem>_<ns>.wav`), guaranteeing synthesized audio is never dropped.
  - **Shielded Artifact Retirement**: Wrapped `InteractiveArtifactStore.remove_if_unprotected` against `OSError` on locked files and guarded `release_retired_artifacts` with exception suppression to prevent slot crashes during background cache cleanup.
  - **Playback Stop Prior to Preview Overwrite**: Halts active file playback before denoise preview generation or voice operations, utilizing retry-bounded atomic overwrites to avoid conflicting with active audio streams.
  - **Safe Export Copying**: Wrapped `shutil.copyfile` in bounded retry loops across `exportWav`, `AudiobookLibrary.export_chapter`, and audiobook batch chapter export.

- **🌐 Cross-Platform Path Normalization (`src/vienetts_app/core/paths.py`)**
  - **Comprehensive Path Utility**: Added a dedicated cross-platform path normalization utility handling edge cases across Windows, macOS, and Linux:
    - Normalizes QML `QUrl` string formats (`file:///C:/...`, `file:///home/...`, `file://localhost/...`).
    - Decodes URL percent-encoded characters (spaces, UTF-8 Vietnamese diacritics, and punctuation).
    - Strips surrounding quotes from drag-and-dropped file paths.
    - Robustly handles Windows extended-length paths (`\\?\`, `\\?\UNC\`) and network shares.
    - Sanitizes Windows reserved device names (`CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`) and trailing spaces/dots in output filenames.
  - **Universal Integration**: Applied path normalization across document importers (`import_document`), audiobook EPUB imports and chapter WAV exports, batch synthesis queue (`BatchFileController`), playback controller (`PlaybackController`), and main app controller.

- **📄 Document Importer & Encoding Hardening (`src/vienetts_app/core/importers.py`)**
  - **BOM-Safe Text Decoding**: Implemented `utf-8-sig` decoding in `importers.py` to seamlessly strip UTF-8 Byte Order Marks (`\ufeff`) from text files imported into Text and Paragraph studios.
  - **Universal Newline Translation**: Text document reading now standardizes Windows (`\r\n`) and legacy Mac (`\r`) line endings cleanly across all platforms.

- **📢 Actionable Worker Error Diagnostics (`InferenceWorker._safe_error`)**
  - **Classified Failure Reporting**: Enhanced `InferenceWorker` error formatting to identify and present actionable messages for specific system resource constraints:
    - **Out of Memory**: Classifies `MemoryError` and CUDA/CPU memory exhaustion, advising on memory limits.
    - **Permission Denied**: Classifies `PermissionError` when accessing model or output paths.
    - **Disk Space Exhaustion**: Classifies disk-full conditions.
  - Eliminates opaque generic error messages, providing users with actionable diagnostic context in the UI.

- **✨ Voice Management & UI Polish**
  - **Voice Name Sanitization**: `TTSEngine.add_voice` now trims whitespace and validates against empty voice names with a clear localized error message (*"Tên giọng không được để trống"*).
  - **Voice Clip Path Preservation**: Preserves relative or local file paths that do not begin with `file://`, while cleanly stripping quotes and normalizing URLs.
  - **VoicePicker Label Regex**: Cleaned up leading hyphen handling in `VoicePicker.qml` regex for cloned voice display labels (`/^[▸—\-]\s*/`).

- **🛡️ Test Suite Coverage & Verification**
  - Added unit test suites `tests/unit/test_crash.py` and `tests/unit/test_paths.py`.
  - Expanded test coverage across `test_artifacts.py`, `test_controller.py`, `test_audiobook_controller.py`, and `test_importers.py`.
  - Full test suite passing with 917 tests (902 passed, 15 device-specific benchmarks skipped).

### 💡 Notes for First-Time Users

1. **Model Weights (~330 MB, one time)**: not bundled in the installers — the app downloads and verifies the official CPU baseline automatically on first launch. You can also import a verified offline pack (`backbone/` + `codec/`) directly via Settings. After that it runs fully offline.
2. **macOS Gatekeeper**: the build is ad-hoc signed. On **Sequoia/Tahoe**, open the app once, then go to **System Settings → Privacy & Security → Open Anyway**; on **Sonoma and earlier**, right-click `VieNeuTTS.app` → **Open** → **Open**; any version via terminal: `xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app`.
3. **Linux Prerequisites**: `sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0`.
