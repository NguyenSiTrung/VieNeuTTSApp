## VieNeuTTS v0.1.14 — Pro Audio Studio, Async Transport & Performance Polish

This release elevates the Audio Studio to a professional DAW-grade experience
with a telemetry-enabled redesign, non-blocking background rendering, an interactive
pause/seek transport, reliable undo/reset synchronization, and massive test suite
consolidation.

### Added

- **Pro-Audio Studio Deck & Master Telemetry:** Redesigned Studio tab featuring an
  expanded 72px master waveform deck with real-time telemetry monitors (Peak level,
  RMS dB, and Dynamic Range meters).
- **Grouped FX Rack:** Reorganized studio operations into three intuitive modular
  sections: Dynamics (Gain, Peak Normalization), Tempo & Cadence (WSOLA Speed stretch,
  Inter-clip gap insertion), and Transitions (Fade In/Out, Silence Trimming).
- **Op Stack Timeline & Contextual History:** Live visual breadcrumbs displaying
  the active chain of operations with one-click contextual Undo and Reset actions.
- **Interactive Transport (Pause & Waveform Seek):** Studio audio transport now
  supports pausing and resuming at the exact playhead position, alongside direct
  click-and-drag waveform seeking via the shared audio player.
- **Per-Clip Auditioning & Transcript Editing:** Listen to individual segments
  directly with per-clip preview buttons, inspect visual badges for re-synthesized
  clips, and edit segment text directly in the re-generation dialog before re-rendering.
- **Comprehensive Bilingual Localization:** 100% Vietnamese and English localization
  for all new studio cards, telemetry readouts, dialogs, badges, and tooltips.

### Fixed & Improved

- **Non-Blocking Background Waveform Rendering:** Audio overview generation, preview
  rendering, and exports now execute off the GUI thread behind a responsive busy
  indicator (`studioBusy`) with per-op spinners, preventing UI freezes during long audio edits.
- **Truthful Waveform Overview:** Audio overview bands are now normalized against
  the dry project peak so Gain adjustments and Peak Normalization visibly scale
  the waveform deck, and Undo restores the original visual amplitude.
- **Undo / Reset Preview Invalidation & Controls Sync:** Performing Undo or Reset
  immediately halts obsolete playback, recalculates the remaining op stack, and auto-plays
  the updated mix. Rack sliders (gain, speed, gap, fade) now faithfully restore to their
  prior positions via dynamic controls synchronization.
- **Stale Render Generation Guards:** In-flight background renders are safely discarded
  when the project or op stack changes, preventing outdated audio mixes from playing.
- **Test Suite Consolidation & Speed:** Merged related micro-tests across unit suites,
  consolidated benchmark tests into `test_benchmark_pack.py` with opt-in execution
  (`-m 'not benchmark'`), and unified QML smoke scenarios into shared subprocesses.
- **CI Reliability:** Removed preinstalled Google Chrome apt source from Linux CI
  runners to prevent transient package manager hash sum failures, and adjusted smoke
  timeouts on loaded runners.
