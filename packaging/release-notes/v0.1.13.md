## VieNeuTTS v0.1.13 — Mini Audio Studio + Segment Re-generation

This release introduces the Mini Audio Studio, enabling users to preview,
refine, reorder, and selectively re-synthesize audio before final export,
alongside export format polish and CUDA requirement hints.

### Added

- **Mini Audio Studio:** A dedicated post-synthesis studio tab for fine-tuning
  and polishing TTS audio before final export without touching the cloud or
  requiring external audio editors.
- **Offline Audio Refinements:** Non-destructive op stack including Gain
  (-20 to +12 dB), Fade In/Out (up to 1000 ms), Speed adjustment (0.5× to 2.0×
  via WSOLA time stretch), Inter-clip gap insertion (0 to 2000 ms), Peak
  Normalization, and Silence Trimming.
- **Live Waveform & Playhead Tracking:** Full amplitude waveform with live
  playhead gliding, accent gradient highlight, elapsed/total duration timers,
  and a Play/Stop toggle for instant auditioning.
- **Reset to Default:** One-click reset in the Audio Refinements card to restore
  the original audio and return all sliders to their standard values.
- **Multi-Clip Manager:** Segment breakdown for multi-paragraph or chapter
  audio, complete with clip index badges, duration indicators, text excerpts,
  and reordering controls (`↑` / `↓`).
- **Segment Re-synthesis (Modal Dialog):** Re-generate individual sentences or
  paragraphs using a different voice without re-rendering the whole document.
  Slices and crossfades seamlessly with a 10 ms smooth blend.
- **Feeder Navigation:** Direct "Studio…" entry buttons on Text, Paragraph,
  and Audiobook tabs, allowing seamless transition from generation to editing.
- **Comprehensive Bilingual Support:** 100% localized in both Vietnamese and
  English across all new Studio surfaces, dialogs, tooltips, and status messages.

### Fixed

- **Export Format in Save Dialogs:** Text, Paragraph, and Audiobook Save dialogs
  now honor the `exportFormat` setting (WAV / MP3) with dynamic filter selection
  and default suffix completion.
- **CUDA UI Driver Guidance:** Inactive CUDA install button now provides an
  informative tooltip explaining driver requirements when no compatible NVIDIA
  driver is detected.
