## 🚀 VieNeuTTS v0.1.7 — Multi-File Batch Synthesis, Instant Voice Switching & Cancellation Hardening

A feature and stability release for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop workstation powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio synthesis run 100% locally on your machine — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **📑 Multi-File Batch Synthesis Queue on Paragraph Tab (`BatchFileController` & `BatchQueueCard`)**
  - **Off-Thread Batch Document Import**: Select or drop multiple document files (`.txt`, `.md`, `.docx`, `.pdf`, `.srt`) directly into the Paragraph Studio. Off-thread parsing keeps the GUI smooth and responsive, while an oversize guard protects against out-of-memory errors on giant documents.
  - **Smart Drag & Drop Routing**: Dropping multiple files anywhere onto the Paragraph tab automatically routes them to the Batch Queue; dropping a single file preserves the standard single-document editor import.
  - **Sequential Auto-Run with Bulk Streaming**: Processes each document sequentially using the background streaming pipeline (`submit_stream_for_listener(kind="bulk")`), without blocking the user interface.
  - **Per-File Auto-Export**: Each finished document's audio is automatically exported as `<stem>.wav` to the chosen output directory, featuring collision-safe suffixing (`_2.wav`, `_3.wav`) to prevent accidental overwriting of existing audio files.
  - **Interactive Batch Queue Card**: Visual per-file progress bars, state badges (*Chờ xử lý / Queued*, *Đang tổng hợp / Synthesizing*, *Hoàn thành / Done*, *Lỗi / Error*), direct Play / Reveal in Folder / Remove actions per item, and a Run All / Cancel footer with queue progress summary.
  - **Voice & Settings Synchronization**: Batch rendering automatically synchronizes with the active voice preset, reading speed, and sentence pause settings selected on the Paragraph tab.
  - **Failure-Continue Resilience**: If an individual document fails during processing (e.g. unsupported encoding or corrupt formatting), the queue reports the error on that item and continues processing the rest of the queue uninterrupted.
  - **Disk Space Preservation**: Automatic lifecycle cleanup removes intermediate synthesis chunk artifacts once a batch item is successfully exported to disk.

- **⚡ Instant Voice Preset Switching & Cancellation Responsiveness**
  - **Immediate Audition Termination**: Selecting a voice in the VoicePicker instantly halts any active audition sample playback (`controller.stopAudition()`), eliminating re-generation delays and playback overlap when changing voices.
  - **Thread-Safe Cancellation Queue Tracking**: Added `_cancel_requested_ids` with lock-based tracking in `InferenceWorker` to eliminate race conditions where a cancelled job could begin synthesizing if dequeued concurrently with the cancel call.
  - **Early Abort Check in Synthesis Loop**: Synthesis chunks check cancellation status before writing to the PCM transport (`_emit_audio_chunk`), preventing unnecessary computation and audio buffer writes after cancellation.
  - **Real-Time Cancellation UI Feedback**: Updated Text and Paragraph tab action buttons with live status states (*Đang chờ xử lý… / Queued…*, *Đang hủy… / Cancelling…*, spinners, and disabled states) for immediate visual confirmation when cancelling queued or active synthesis jobs.
  - **Clean Controller Teardown**: Fixed edge cases in `AppController.cancel()` ensuring UI busy state and job states are always cleanly reset even if no foreground job ID or worker is active.

- **🌐 Expanded Bilingual Localization (i18n)**
  - Regenerated English localization catalogs (`vienetts_en.ts` and compiled `.qm`) with complete translations for all new batch synthesis queue elements, queue item actions, and cancellation states.
  - Filled previously missing English translations for update checking, model downloading, and live preview toggles.

- **🛡️ Quality & Test Suite Coverage**
  - Added unit tests for `BatchFileController` covering document import, queue ordering, sequential progression, collision-resistant export naming, error tolerance, and artifact cleanup.
  - Added tests for voice picker audition termination, cancel tracking, and controller cancel state resets.
  - Entire suite of 866 tests passing (865 passed, 1 device-specific skipped).

### 💡 Notes for First-Time Users

1. **Model Weights (~330 MB, one time)**: not bundled in the installers — the app downloads and verifies the official CPU baseline automatically on first launch. You can also import a verified offline pack (`backbone/` + `codec/`) directly via Settings. After that it runs fully offline.
2. **macOS Gatekeeper**: the build is ad-hoc signed. On **Sequoia/Tahoe**, open the app once, then go to **System Settings → Privacy & Security → Open Anyway**; on **Sonoma and earlier**, right-click `VieNeuTTS.app` → **Open** → **Open**; any version via terminal: `xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app`.
3. **Linux Prerequisites**: `sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0`.
