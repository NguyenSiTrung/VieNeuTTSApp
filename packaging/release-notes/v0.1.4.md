## 🚀 VieNeuTTS v0.1.4 — Artifact-First Streaming, Memory Bounds & Windows Reliability

A patch release for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop app powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio processing run 100% locally — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **⚡ Artifact-First Synthesis & Bounded Memory**
  - Synthesizing very long texts or audiobooks previously accumulated all audio chunks in RAM and concatenated them into a single massive buffer, causing peak memory usage to exceed 2.5 GB RSS and risking out-of-memory crashes on low-memory devices.
  - Synthesis now writes validated 48 kHz 16-bit mono WAV artifacts incrementally directly to disk (`IncrementalArtifactWriter`), atomically promoting the completed file once generation succeeds.
  - Streaming playback is powered by a bounded thread-safe PCM transport (`BoundedPcmTransport`), ensuring real-time playback uses predictable, strictly bounded memory.
  - Replay and export now stream directly from on-disk artifacts (`InteractiveArtifactStore`), drastically lowering RAM footprint across long synthesis sessions.
- **🪟 Windows `MAX_PATH` & Model Download Fixes**
  - Resolved model download failures on Windows caused by the 260-character path limit: `ModelManager` now passes the repository root as `local_dir`, eliminating duplicated subpaths in staging and cache directories.
  - Added Windows extended-length path (`\\?\`) normalization and same-file detection, ensuring reliable file staging and preventing promotion errors on Windows.
  - Configured `default_data_dir()` with `appauthor=False` on Windows to eliminate redundant `VieNeuTTSApp\VieNeuTTSApp` nesting in `%LOCALAPPDATA%`, with automatic migration of existing app data.
- **🔒 Windows File Locking & Stability**
  - Fixed Windows `PermissionError` file-locking issues caused by active ONNX runtime sessions holding file handles during model updates, imports, or chapter writes.
  - Added explicit garbage collection (`gc.collect()`) upon engine closure and guaranteed worker shutdown before installing or importing models.
  - Implemented atomic writes with unique temporary filenames and cross-thread synchronization (`_book_lock`) for audiobook chapter persistence.
- **🌐 Upstream `codec_dir` Injection (Zero Unwanted Network Calls)**
  - Fixed an issue where upstream `vieneu` 3.3.0 dropped `codec_dir` during inner engine initialization, causing unexpected network download attempts to Hugging Face during synthesis even in offline mode.
  - The engine now explicitly injects `codec_dir`, ensuring synthesis strictly uses the local model directory without external requests.
- **📦 Packaged App Error Guidance**
  - In frozen builds (Windows `.exe`, macOS `.app`, Linux bundle), missing model files now provide clear user guidance to download via the in-app setup card or import an offline pack, replacing developer-centric CLI instructions.
- **🛡️ Windowed Executable UTF-8 Stdio Safety**
  - GUI-only mode (`console=False`) redirects stdio to `os.devnull` with explicit `utf-8` encoding and `replace` error handling, preventing application crashes when non-ASCII error messages or tracebacks are emitted.

### 💡 Notes for First-Time Users

1. **Model Weights (~330 MB, one time)**: not bundled in the installers — the app downloads and verifies the official CPU baseline automatically on first launch. You can also import a verified offline pack (`backbone/` + `codec/`) directly via Settings. After that it runs fully offline.
2. **macOS Gatekeeper**: the build is ad-hoc signed. On **Sequoia/Tahoe**, open the app once, then go to **System Settings → Privacy & Security → Open Anyway**; on **Sonoma and earlier**, right-click `VieNeuTTS.app` → **Open** → **Open**; any version via terminal: `xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app`.
3. **Linux Prerequisites**: `sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0`.
