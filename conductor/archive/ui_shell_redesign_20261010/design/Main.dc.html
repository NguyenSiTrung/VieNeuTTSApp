VIENEUTTS DESKTOP · v0.1.14 · QML / PySide6 · AUDITED 10 OCT 2026

Keep the design system. Rebuild the shell around the job.

The Signal tokens and component library are solid. The problems are structural: navigation split by input length, a primary action that moves between screens, and chrome that crowds out content. That is a refactor plus a shell redesign, not a full visual rewrite.

Keep

  • Signal palette: slate surfaces, teal accent, success shifted green. It sounds like audio, not like generic AI.
  • Be Vietnam Pro, which is built for Vietnamese diacritics.
  • The component kit (AppButton, AppCard, VoicePicker, SynthesisBar, PlaybackWaveform)
  • The accessibility work: contrast-measured waveform bars, readable disabled states, focus rings, objectName test contract

Refactor

  • Density: remove card subtitles, dividers and the icon tile on every row
  • Type floor: no text below 12 px (fontSizeXs is 10 px today)
  • Button hierarchy: one primary per screen, with a split button for export
  • Status: one status bar instead of four scattered surfaces
  • Hit targets: raise controlHitTarget from 40 to 44 px

Redesign

  • Information architecture: merge Văn bản and Đoạn văn into Tạo giọng đọc, and add a Giọng đọc library
  • One transport dock (voice, generate, waveform, export) on every synthesis screen
  • Studio: a timeline plus an effects panel, not a stack of cards
  • Sách nói: master–detail with no nested scroll
  • Cài đặt: sub-navigation, with expert options behind disclosure
