## VieNeuTTS v0.1.11 — Managed CUDA Runtime

This release keeps every desktop download CPU-only and adds an opt-in,
app-managed CUDA runtime for supported NVIDIA systems.

### Added

- **Explicit CUDA installation:** Windows x64 and Linux x64 users with a
  CUDA 12.8-compatible NVIDIA driver can download the verified PyTorch runtime
  from Settings after installing the regular CPU application.
- **Verified offline runtime:** the app validates the pinned wheel files before
  installing them in its per-user data directory. CUDA works without network
  access after a successful installation.
- **Safe diagnostics and removal:** Settings reports the managed runtime and
  driver prerequisites without running a locally detected Python environment.
  A ready inactive runtime can be removed; restart the app if CUDA was already
  loaded.

### Changed

- Windows and Linux release artifacts no longer include multi-gigabyte CUDA
  bundles. macOS remains CPU-only.
