# Codebase Patterns

Reusable patterns discovered during development. Read this before starting new work.

## Code Conventions

- Dev loop: `uv venv --python 3.13 .venv` (SDK caps at 3.13; system python may be newer), install `-e ".[dev]"`, gates via `.venv/bin/{ruff,pytest}` (with default parallel test runner `pytest-xdist` `-ra -n auto`); set `QT_QPA_PLATFORM=offscreen` for pytest (from: phase01_core_20260827, 2026-08-27; reconfirmed in phase02_uishell_20260827 with PySide6 6.11.2; xdist enabled 2026-08-28).
- Tiered pytest runs: while iterating use `pytest tests/unit` (~16–22 s); full `pytest` (~32–43 s wall on this 18-core box, 1579 selected / 1597 collected, 18 benchmark deselected, 2026-10-23 after `42ab565`; add `-m "not slow"` for an even faster loop — 1557 selected, 40 deselected — and `-m "not slow and not benchmark"` for 1539) is the pre-commit gate per the quality rule below. There is NO per-commit CI — `.github/workflows/ci.yml` was removed 2026-10-10 (`88f6dbb`, bead `1iqy`); the tag-triggered `release.yml` is the only automatic gate and runs ruff + the full offscreen suite on Windows/macOS/Ubuntu before building. `addopts` carries `--dist worksteal` (xdist's default `load` left the long smoke tests as a tail: 175 s vs 85 s with identical tests). Unset `PYTHONDONTWRITEBYTECODE` for test runs or pytest re-rewrites every test module on every worker (+~7 s) (from: bead VieNeuTTSApp-e6b 2026-08-31; zc8p 2026-10-10; 7coj 2026-10-12; updated 2026-10-23).
- `QT_AUDIO_BACKEND=ffmpeg` in tests needing the real player (the tag-triggered `release.yml` sets it globally — there is no per-commit CI since 2026-10-10); `QMediaPlayer` has no `resume()` (play() resumes) (from: phase03_corefeat_20260827 + ci fix 3ffabd0, 2026-09-03; updated 2026-10-21).
- Qt allows ONE QGuiApplication per process and QML ABORTS the interpreter if only a headless QCoreApplication exists — GUI-object-tree assertions in pytest must run in a subprocess (`sys.executable -c` + RESULT: json stdout line) (from: phase02_uishell_20260827, 2026-08-27).
- `setContextProperty` does NOT take ownership of the Python object: anchor it (e.g. `engine._bridge = bridge`) or GC collects it and QML bindings see `null` (from: phase02_uishell_20260827, 2026-08-27).
- QML files should live in one dir and use same-directory `import "."` for the Theme singleton (registered in qmldir); the engine needs `addImportPath(qml_dir)` — bare absolute-path imports are rejected (from: phase02_uishell_20260827, 2026-08-27).
- `findChildren(QObject, name)` returns generic QObject wrappers — read QML-declared properties via `.property("name")`, not attribute access; StackLayout instantiates ALL children, so use currentIndex for visibility, not existence (from: phase02_uishell_20260827, 2026-08-27).
- Wayland blocks QScreen.grabWindow (0×0) without an XDG portal — for "window shows" evidence assert `isExposed()` + live event loop (from: phase02_uishell_20260827, 2026-08-27).
- QML teardown must be DETERMINISTIC: call `_teardown_qml()` after `app.exec()` while the context-property anchors (engine → bridge/controller/playback) are still alive. Interpreter-shutdown global clearing order is arbitrary; when `engine` dies first the surviving QML tree re-evaluates bindings against null and floods ~186–192 "Cannot read property 'x' of null" TypeErrors. The old "harmless post-quit stderr noise" reading was wrong — that noise was this defect (fixed 5a578eb, v0.1.14).
- `QGuiApplication.styleHints().colorScheme()` reports Unknown under offscreen/no-platform → treat as dark (the app's safe default); real light/dark only appear on a live desktop session (from: phase02_uishell_20260827, archived 2026-08-27).
- Quality gate per task: `ruff check .` + `ruff format --check .` + `pytest` must all pass before committing; commit with conventional prefix + `git notes add` task summary (from: phase01_core_20260827, 2026-08-27).
- Ruff excludes `.agents/`, `conductor/`, `*.md` (tooling and frozen planning docs are not app code; ruff 0.16 otherwise formats Python inside Markdown) (from: phase01_core_20260827, 2026-08-27).
- Parallel sub-agents sharing a git index hit `index.lock` occasionally: serialize commits through the orchestrator (retry-after-5s also works); agents run only their scoped tests — the orchestrator runs the full gate before committing; coordinate SHARED UI copy through the orchestrator too — concurrent copy edits caused test ping-pong in phase04 until the final copy pinned all partner phrases verbatim by objectName (from: phase02_uishell_20260827 + phase03_corefeat_20260827 + phase04_streaming_20260827, 2026-08-27).

- QML `var` property signals do NOT fire on in-place array mutation (`samples.push(...)` leaves derived bindings stale) — reassign a fresh array per update so NOTIFY fires (from: phase04_streaming_20260827, 2026-08-27).
- Streaming to UI contract: only NUMBERS cross the Python→QML boundary — Python computes a peak-amplitude envelope (0..1) and emits `levelReady(float)`; raw samples never reach QML (from: phase04_streaming_20260827, 2026-08-27).

- QML Component Libraries & Subfolders: Subfolder components (e.g. `src/vienetts_app/ui/qml/components/`) can be cleanly registered in root `qmldir` with relative paths (`AppCard 1.0 components/AppCard.qml`), or declared via subfolder `qmldir` and consumed via `import "components"` (from: ui_redesign_20260827, 2026-08-27).
- Dynamic Theme Tokens: Theme tokens (`Theme.qml`) bound to a bridge preference (`bridge.effectiveTheme`) should use reactive property bindings rather than static constants, providing instantaneous dark/light updates across all controls without engine or application restart (from: ui_redesign_20260827, 2026-08-27).
- Custom QML ComboBox Delegates: Custom `ItemDelegate` in `ComboBox` popups require `required property var modelData` and `required property int index`, plus `width: combo.width` to ensure popup item clicks and highlights dispatch cleanly without dynamic lookup errors in test suites (from: ui_redesign_20260827, 2026-08-27).
- QML Elevation & Drop Areas: card elevation is ONE analytic `RectangularShadow` (`AppCard.qml`, PySide6 ≥6.9 floor) — never a `MultiEffect` blur pass; a hidden source shape + per-card blur costs a texture per card and `MultiEffect` no longer appears in any QML file (`test_theme.py` pins that). Children funneled through a card's `default property alias` into a ColumnLayout are layout-managed — wrap `DropArea`s in a plain Item or attach inside a Rectangle, never as a direct card child with anchors (from: ui_refine_20260828, 2026-08-28; updated 2026-10-21).
- QML Property API Traps: `TextArea` has `lineSpacing` not `lineHeight`; `font.underline` not `underline`; `RowLayout` has no padding properties (use child `Layout.*Margin`); same-directory components resolve implicitly — from inside `components/` import only `".."` for Theme (from: ui_refine_20260828, 2026-08-28).
- Bundled QML Fonts: `FontLoader` sources resolve relative to the QML file — ship TTFs under `ui/qml/fonts/`; a `pragma Singleton` QtObject may own FontLoaders and expose the family via the NOTIFY `name` so `fontFamily` flips system-fallback → bundled family reactively (Be Vietnam Pro, OFL) (from: ui_refine_20260828, 2026-08-28).
- Screenshot Verification Harness: `QQuickWindow.grabWindow()` captures the QML scene WITHOUT macOS screen-recording TCC permission (`QScreen.grabWindow` silently returns empty); drive with FakeController/FakePlayback via `create_app` factories, tab/theme/state scripted with QTimer settles (from: ui_redesign_20260827 + ui_refine_20260828, 2026-08-28).
- Audiobook/subtitle/batch seam (one engine, many consumers): route worker results through a PER-JOB listener registered by `submit_stream_for_listener(text, voice, listener, *, kind=..., context=...)` on AppController, which returns `{job_id: listener}` and detaches it on the terminal frame; it returns `None` (registering nothing) when validation or worker admission fails, and it NEVER sets `busy` because listener jobs are not foreground. There is no `attach_synthesis_listener` API any more. Never build a second InferenceWorker — two workers means two model loads (~800 MB each) (from: audiobook_epub_20260828, 2026-08-28; corrected 2026-10-21).
- Atomic audio-file writes must keep the target extension (`x.part.wav`), because soundfile infers the container format from the path suffix — `x.wav.tmp` raises "No format specified" (from: audiobook_epub_20260828, 2026-08-28).
- Hidden StackLayout tabs have UNSETTLED bindings: `property("visible")` reads stale values until the tab becomes current — activate the tab + processEvents before asserting its UI state in drivers; delegate-order from childItems() walks is arbitrary, so select delegates by `modelData` and count conditional children by their `visible` property; QML data fakes need real NOTIFY `@Property` members (plain Python attributes read as undefined). `QMetaObject.invokeMethod(item, "click")` works for Controls, "toggle" does not (from: audiobook_epub_20260828, 2026-08-28).
- Keyboard focus ring for a11y: `activeFocus && (focusReason === Qt.TabFocusReason || focusReason === Qt.BacktabFocusReason)` displays focus visual rings exclusively for keyboard navigation while keeping pointer clicks clean and free of spurious outlines (from: ui_refine_20260828, 2026-08-28).
- VoicePicker / ComboBox non-circular reactivity: direct `currentIndex` binding to a controller property that can be mutated by user selection creates circular binding loops; use imperative sync on `Component.onCompleted` plus a declarative `Connections` handler on the changed signal instead (from: ui_refine_20260828, 2026-08-28).
- QML animation loops: drive with a ~33ms Timer that STOPS itself once the animation settles (all values at target) and restarts on the next change — a always-running repaint loop burns CPU at idle; glide/lerp toward targets inside the tick, never jump (from: bead-driven waveform work a6r/yi5/56h, 2026-08-29).
- Every byte/count property exposed to QML must be `qlonglong`, never Qt `int` (32-bit): the linux-x64 managed-CUDA manifest needs 7,923,412,460 bytes, which raised `OverflowError` inside a SettingsTab binding and unwound through `ShellBridge.setCurrentTab` → `currentTabChanged.emit()` into the crash handler. Format multi-GB labels as pre-formatted strings — QML number-to-text renders them as "7.92341e+09" (from: commit 5a578eb, 2026-09-10).
- Tall-tab layout rule: a single stacked content column past the viewport buries the primary CTA behind scroll (ParagraphTab was 948 px tall against a 652 px viewport → CTA 208 px below the fold). Split mutually exclusive workflows into segmented modes (`ModeTabs`) over separate surfaces and move global actions into a docked bar (`SynthesisBar`); `PageShell.stretch` lets a populated list fill the page instead of leaving a void (from: commit 0d684ba, 2026-09-10).
- Localize catalog metadata at DISPLAY time: VoicePicker maps region/gender/style tags per locale (region → "Miền …", translated gender/style with disambiguation comments) so a southern male voice stops rendering two identical "Nam" chips and the English UI never shows Vietnamese catalog metadata while the catalog model itself stays untouched (from: commit 0d684ba, 2026-09-10).
- Text-pin rule for custom control skins: the smoke/unit suites read the CONTROL's own `text` property (`denoiseCheck.property("text")`), so a custom `contentItem` must MIRROR `control.text` (bind to it, or write back through the control) rather than replace the property's value — a skin that only renders the label internally reads back empty to every assertion (from: ui_refine_20260828, archived 2026-09-21).
- Inline `component` templates declared inside a tab are trap-prone: `parent.parent.label`-style lookups and default-property aliasing silently bind to the wrong object and break on the next refactor — declare explicit rows/items instead, and keep reusable pieces in `ui/qml/components/` registered through `qmldir` (from: ui_refine_20260828, archived 2026-09-21).
- One skin per control, no per-tab restyling: every button goes through `AppButton`, every combo through `AppCombo`, voice lists through the shared `VoicePicker` (tabs contain ZERO inline Button backgrounds), and `AppIcon`'s Canvas switch (kind string → 20×20 vector) is the only icon source — restyling is then a single-file change and the smoke `objectName` contracts survive UI extraction (from: ui_refine_20260828, archived 2026-09-21).
- Responsive tab posture: wrap tab contents in a `ScrollView` with `contentWidth: availableWidth` and a centered max-width column (`Math.min(840, root.availableWidth - Theme.spacingLg * 2)`) so the same layout is usable from the 640×420 minimum window to 1440×900+ without horizontal clipping; a `Repeater` nested in a `ColumnLayout` needs its delegates wrapped in a real control with an explicit `Layout.fillWidth`, or the layout collapses (from: ui_redesign_20260827, archived 2026-09-21).
- CheckBox strict-binding write-back is SAFE (and preferred): a strict `checked: controller.flag` binding survives the C++ `toggle()` (which does not break the binding) and `onToggled:` syncs the controller, with the NOTIFY re-evaluation keeping the two consistent — do not replace it with imperative sync just because the property is written from QML (from: audiobook_epub_20260828, archived 2026-09-21).
- A QML singleton (`pragma Singleton`) must be declared in BOTH `qmldir`s — the root one with a RELATIVE path (`singleton EngineState 1.0 components/EngineState.qml`) and the `components/` one — or it resolves for the root module only. `Theme` and `EngineState` both carry the pair (from: qwen_multiengine_20260920, 2026-09-21; verified 2026-10-21).
- User-only activation signal on fallback-syncing pickers: a component that auto-selects a fallback during `syncSelection` (`VoicePicker`) must expose a user-only signal (`voiceActivated(id)`) emitted solely from the click/keyboard activation path — binding a controller write to `onSelectedVoiceChanged` silently rewrites every row's speaker mapping on first paint (from: `subtitles_ux_overhaul_20261023` Phase 3, archived 2026-10-23).
- Component-owned `disabledReason` & accessibility contract: `disabledReason` (rendering tooltip + `Accessible.description` when `!enabled && disabledReason.length > 0`) and `Accessible.name` belong on the shared controls (`AppButton`, `AppToggle`, `AppCombo`, `AppSlider`, `AppNumberField`, `AppProgressBar`, `AppTextField`), not at 40 call sites; hosts only supply the label and gate sentence (from: `subtitles_ux_overhaul_20261023` Phases 3–4, archived 2026-10-23).

## Architecture

- `Vieneu` is a factory FUNCTION (`Vieneu(mode="v3turbo", backend=..., precision=...)`), not a class; kwargs pass through to the engine. Full confirmed contract: `docs/spike-report.md` §0 (from: phase01_core_20260827, 2026-08-27).
- Engine ownership: exactly one `TTSEngine` (lazily initializes its Vieneu) owned by one `InferenceWorker` QThread; requests serialize through its queue; cancel is cooperative between stream chunks (from: phase01_core_20260827, 2026-08-27).
- Voice keys: `list_preset_voices()` → `[(label, voice_id)]`; **voice_id (element [1])** is the key for `infer(voice=...)`; labels encode gender·region·style for North/Central/South grouping (from: phase01_core_20260827, 2026-08-27).
- Offline bundling: portable `HF_HOME` + `HF_HUB_OFFLINE=1` with pre-seeded cache; the codec repo is NOT dir-loadable via the public API; minimal CPU bundle via `scripts/fetch_models.py` (327 MB, SHA256 manifest) (from: phase01_core_20260827, 2026-08-27).
- ONNX precision→subfolder map: int8 → `onnx_int8`, fp32 → `onnx_update` (NOT `onnx/` as the plan sketch assumed) (from: phase01_core_20260827, archived 2026-08-27).
- `snapshot_download(..., local_dir=..., allow_patterns=[...])` writes a `.cache/huggingface` metadata dir INSIDE the bundle — always exclude it from manifests/hashes (from: phase01_core_20260827, archived 2026-08-27).
- Streaming contract: `infer_stream` yields float32 1-D mono chunks of variable size (~15360–96000 samples); concatenate for full audio. It carries its own sampling defaults (temperature=0.8, top_k=25, top_p=0.95), different from `infer` (temperature=0.4, top_k=50) (from: phase01_core_20260827, archived 2026-08-27).
- vieneu voice persistence: `save_voices(path)` writes ALL voices; there is NO custom-path LOAD api (init always reads site-packages assets). App-owned persistence = save to `<app data>/voices/voices.json` + merge-back into `tts._preset_voices` at engine init; `add_voice` must always pass `save=False` (from: phase03_corefeat_20260827, 2026-08-27).
- vieneu preset catalog is model-free: read `Path(vieneu.__file__).parent/assets/voices_v3_turbo.json` (20 presets; description format `gender · region · style` — middle token is the region for N/C/S grouping). Asset shape: top-level meta/default_voice/presets (from: phase03_corefeat_20260827, 2026-08-27).
- EPUB spine href normalization: EPUB spine hrefs are percent-encoded and relative to the OPF directory — apply `urllib.parse.unquote`, normalize forward slashes, and prefix the OPF directory; nav/cover documents are identified and filtered via `properties="nav"` and non-blank text extraction checks (from: audiobook_epub_20260828, 2026-08-28).
- Persist derived data as a sidecar JSON next to its source artifact (`ch_XXXX.waveform.json` beside `ch_XXXX.wav`): write atomically, treat absent/corrupt as a cache miss, and recompute ONCE from the source — deferred off the load path via `QTimer.singleShot(0, ...)` with a state-unchanged guard — for artifacts created before the sidecar existed (from: bead-driven waveform work a6r/yi5/56h, 2026-08-29).
- Shared-subprocess QML smoke drivers: run a LIST of scenarios per subprocess (one QGuiApplication, fresh engine+fakes per scenario via `create_app`'s instance() reuse, deterministic `engine.deleteLater()` + `gc.collect()` + `processEvents()` between scenarios); the driver prints one `RESULT:` mapping scenario→out and the pytest side rebinds `result = results["<scenario>"]` between assertion blocks — merging N launches into one saves ~1 s each (from: bead VieNeuTTSApp-6ex, 2026-08-29). Each scenario still costs >=1 s of real QML instantiation (`processEvents`), so scenarios that start from the same fake-controller state run back to back in ONE window under a group name (`settings_group`, `clone_group`, …), each member writing its own `results[<name>]` key and join lines resetting the fake state it dirtied (e.g. `controller._busy`) — 62 → ~25 instantiations in zc8p; keep scenarios separate when leftover QML flags could give a false pass (Qwen setup dialog state machine) (from: zc8p, 2026-10-10).
- QGuiApplication-level state leaks ACROSS engines in one process: `create_app` installs its language translator on the app, and destroying the engine does NOT remove it — sequential in-process "fresh boot" phases must `app.removeTranslator(engine._translator)` before teardown or a vi-boot phase renders English from the previous en phase (from: bead VieNeuTTSApp-6ex, 2026-08-29).
- PyInstaller frozen-build layout contract: data trees (`vieneu`/`vieneu_utils` voice+sample assets, `sea_g2p`'s ~60 MB Rust dictionary, `kaldi_native_fbank` dylibs) must land INSIDE the frozen `vienetts_app` package at the same relative layout the source tree uses — then `Path(__file__).parent`-relative resolution (e.g. `QML_DIR`) needs zero frozen-mode code paths. Lazily-imported engine submodules (`vieneu.factory` imports inside functions) require `collect_submodules` hiddenimports or every infer dies with ENOENT on `sea_g2p.bin`; torch/transformers are EXCLUDED deliberately to keep the CPU build torch-free (from: release-pipeline work 9bf0ce8, 2026-08-29).
- GUI-thread offload for one-shot heavy ops (`ui/bg_ops.py`, `ui/chapter_persist.py`): run the callable as a `QRunnable` on the global Qt thread pool and marshal the result back through a queued signal; controllers take an injectable `bg_runner` (production = thread pool, tests = `run_sync`) for deterministic inline completion. The callback re-validates identity (book id) before touching state — the same straggler-guard discipline as worker signals (from: beads VieNeuTTSApp-12k/dfe/00w, 2026-09-02). `run_sync` cannot reorder completions — test stale-completion logic with a `DeferredRunner` (queue work, then `run(i)` in any order), and once a slot goes async, every test that builds the controller without `bg_runner` needs `bg_runner=run_sync` or it falls back to the real pool (from: perf_hardening_20261009, 2026-10-09, Task 2.2).
- Streaming buffer economics: on the audio hot path hand out zero-copy chunk views, grow worker buffers by doubling, and use an offset-based `StreamIODevice` with amortized compaction — never per-chunk full-array copies (from: commit 47e7813, 2026-09-02).
- Artifact-first synthesis (v0.1.4, bead-driven, no track): the worker writes validated 48 kHz mono WAV incrementally via `IncrementalArtifactWriter` (`core/artifacts.py`, `<job>.part.wav` → atomic `os.replace` promote) and feeds live preview through `BoundedPcmTransport` (`core/pcm_transport.py`, 2 s / 384 KB cap, 150 ms prebuffer) — no duration-sized RAM arrays; both replay and export read the artifact (from: commits in v0.1.4 release, 2026-09-03).
- Job-contract routing (v0.1.3, bead-driven, no track): immutable job values (`core/jobs.py`: SynthesisJob/JobProgress/JobChunk/JobTerminal, incl. audition lane) admitted via thread-safe FIFO (`workers/job_queue.py`, per-ID/per-owner cancel); worker terminals are job_id-tagged and the controller routes by ID, dropping stale deliveries (from: commit 6a17ad6, 2026-09-03).
- Pinned model baseline (v0.1.3, bead-driven, no track): `core/official_model_manifest.py` is the frozen allowlist (backbone + codec repos, revisions, file sizes + SHA-256); `core/model_manager.py` installs staging-only with resume, free-space preflight, atomic promote, and Windows MAX_PATH/long-path handling; `scripts/fetch_models.py` derives everything from the manifest (from: commits d0d6298/e371937/83601fa, 2026-09-03).
- WSOLA reading speed (v0.1.5, bead-driven, no track): `Settings.speed` [0.5, 2.0] + `silence_p` [0.0, 2.0] validated in `core/models.py`, applied as engine infer kwargs + NumPy WSOLA post-stretch in `core/audio.py`; silent generate-then-replay is the default (`live_preview=False` in Settings) with the preview toggle routing through the bounded transport (from: commits e131631/882fa17, 2026-09-03).
- Cancellation race discipline (v0.1.7, bead-driven, no track): lock-tracked `_cancel_requested_ids` in `InferenceWorker` + early abort check before PCM-transport writes (`_emit_audio_chunk`) + controller teardown that resets busy/job state even with no active job; QML action buttons show live queued/cancelling states (from: v0.1.7 release, 2026-09-06…10).
- Managed CUDA runtime (v0.1.11, bead-driven, no track): `core/cuda_runtime.py` + pinned records in `core/cuda_runtime_manifest.py` (rendered by maintainer-only `scripts/lock_cuda_runtime.py`); opt-in Settings download into the per-user data dir, verified before install, offline after; the app never invokes pip or executes locally discovered Python envs; `torchAvailable` probe is lazy/off-thread so cold start stays model-free (from: commits bf195d8/38ae2f8, 2026-09-06…10; supersedes the brief v0.1.9 `-cuda` bundles).
- In-app update checks (v0.1.6, bead-driven, no track): stdlib-urllib GitHub Releases query in `core/updates.py` with platform-aware asset matching (variant-aware during the `-cuda` era), silent check after startup + hourly recheck, Settings badge + manual check button, frozen version stamping with release-time assertion (from: v0.1.6 release, 2026-09-06…10).
- Batch synthesis queue (v0.1.7, bead-driven, no track): `ui/batch_controller.py` + `BatchQueueCard.qml` — off-thread import with oversize guard, smart single-vs-multi drop routing, sequential auto-run via `submit_stream_for_listener(kind="bulk")`, per-file auto-export with collision-safe suffixing, failure-continue, chunk-artifact lifecycle cleanup (from: v0.1.7 release, 2026-09-06…10).
- Mini Audio Studio op stack (v0.1.13, bead-driven, no track): non-destructive gain/fade/speed/gap/normalize/trim ops in `core/studio.py` + `StudioTab.qml`, per-segment re-synthesis with 10 ms crossfade, reached from the Create dock's Studio action and the Audiobook chapter action (the old Text/Paragraph tabs no longer exist) (from: commits 0f11649/55903d7, 2026-09-06…10).
- Pro-audio Studio deck (v0.1.14, bead-driven, no track): renders/exports run off the GUI thread behind `studioBusy` + per-op spinners with stale-GENERATION guards (in-flight renders are discarded when the project or op stack changes); waveform overview bands normalize against the dry-project peak so Gain/Normalize visibly scale the deck and Undo restores amplitude; Undo/Reset halts obsolete playback, recomputes the op stack, resyncs rack sliders, and auto-plays the updated mix (from: commits 55903d7/45138a3/3290961, 2026-09-10; extends the `bg_ops` straggler-guard discipline).
- Create-tab mode composition (v0.1.14 → rewritten by the UI shell redesign; `ModeTabs.qml`, `SynthesisBar.qml`, `ParagraphTab.qml` and `TextTab.qml` no longer exist): `CreateTab.qml` composes an `AppSegmented createModeSwitch` (`compose`/`document`/`files` from `bridge.CREATE_MODES`) over an eager compose editor plus ONE async `Loader` for the secondary modes, with `TransportDock` pinned OUTSIDE the scroll area. Subtitles was moved out of this switch entirely in `aef1d87` (own top-level destination). VoicePicker owns its own model, so the old `buildFlatModel` copies are gone (from: commit 0d684ba, 2026-09-10; extended 2026-09-14; rewritten 2026-10-21).
- Settings card split (v0.1.14, bead-driven, no track): Engine / Managed CUDA runtime / Model source are separate top-level cards; verbose CUDA guidance lives behind a `Details & diagnostics` disclosure (collapsed by default; auto-expands for in-flight/failed installs, unusable driver, or a prior scan; a manual collapse sticks); driver commands are monospace rows sharing a `controller.copyText` seam, and all 21 smoke-contract objectNames are preserved (from: commit 3eb6c90, 2026-09-10).
- Subtitle dub/transcript studio (2026-09-14, bead-driven, no track): three PURE core layers behind one QML controller seam — `core/subtitles.py` (cue model: no Qt, no disk policy), `core/align.py` (fit planning only), `core/subtitle_project.py` (workspace store + streaming renderer) — surfaced by `ui/subtitle_controller.py` as the `subtitleController` context property and surfaced as `SubtitlesTab.qml` (a top-level destination since `aef1d87`), which composes `SubtitleCard.qml`. Two policies: `dub` treats the SRT clock as master (rate-compress an overlong take up to `rateCap`, push later cues on overflow) and `transcript` treats the voice as master (never compress; cap inter-cue pauses). Renders reuse the AppController per-job listener seam (`submit_stream_for_listener(text, voice, listener, kind=..., context=...)`) exactly like Audiobook/Batch — one worker, one model, no second load (from: commits 2068d8d/617cfdc, 2026-09-14).
- Streaming track render + fingerprint cache (2026-09-14): `SubtitleTrackRenderer` writes the mix clip-by-clip to `PCM_16` `track.wav` — a two-hour track is ~690 MB on disk instead of a ~1.4 GB float array in RAM, and every reader goes through `read_wav` which converts back — and `render_fingerprint()` hashes everything that changes the audio, so an unchanged fingerprint reuses the cached track instead of re-synthesizing (NFR-A1). Same discipline as the audiobook chapter cache (from: commit 2068d8d, 2026-09-14).

## Gotchas

- Non-speech ASR tokens share ONE vocabulary: `NON_SPEECH_LABELS` lives in `core/subtitles.py` and is reused by `core/asr.py`, so `[MUSIC]`/`[BLANK_AUDIO]` can never be parsed as a speaker from either a user `.srt` or raw ASR segments. User cancellation gets its own exception subclass (`AsrCancelled`, `DiarizationCancelled`) that the `auto` fallback re-raises immediately instead of swallowing it and trying the next backend (from: asr_hardening_20261021, archived 2026-10-23).
- Separate download PROGRESS from install STATE: throttle the progress signal (`aiDownloadProgressChanged`, >= 0.01 deltas) while the install signal (`aiModelsInstallChanged`) fires only at start/finish/error, so QML never re-runs `stat()`/`rglob()` per 256 KB network chunk (from: asr_hardening_20261021, archived 2026-10-23).
- Managed sidecar files carry an 8-hex digest of the resolved source path (`<stem>_<hash8>.srt`) while the user-facing title keeps the clean stem; the same digest keys the media cache so repeat transcriptions/diarizations reuse the 16 kHz WAV, ASR segments and diarization turns (from: asr_hardening_20261021, archived 2026-10-23).
- In QML drivers, `click()` invokes the handler unconditionally (it bypasses `enabled`); select an enabled instance from the visual tree (the active project row's "Mở" is disabled) instead of assuming row order (from: subtitles_ux_overhaul_20261023, archived 2026-10-23).

- `Window.window` is an attached property that resolves ONLY on Items: evaluating it inside `Connections` (a `QtObject`) returns null with "Window.window only supports types derived from Item", so focus-follow listeners silently never fire. Put `readonly property Window pageWindow: Window.window` on the Item root and target that from `Connections` (found while closing `subtitles_ux_overhaul_20261023`, 2026-10-23).
- Focus-scroll math mixes coordinate spaces easily: `mapToItem(flickable, 0, 0)` yields VIEWPORT coordinates, so comparing it with `flickable.contentY` breaks once the page is scrolled (an in-view item jumps the page to its viewport y). Map into `flickable.contentItem` for content coordinates, and regression-test with `contentY > 0` on an already-visible item (must not move the page).
- Snapshot scalars immediately in QML smoke drivers: never hold a `QQuickItem` reference across a `loaded`/stage toggle or popup close (`popup_item` destroyed on close, `Repeater` cue delegates reflowed) — C++ deletes the underlying item and later reads raise `RuntimeError: Internal C++ object already deleted` (from: `subtitles_ux_overhaul_20261023` Phase 2, archived 2026-10-23).
- Confirmation dialog `onClosed` ordering trap: `Dialog.close()` runs BEFORE the confirm action in `RemoveConfirmDialog`, so a generic `onClosed: reject()` discards the change being confirmed; guard with an explicit `confirming` flag and dedicated cancel handler (from: `subtitles_ux_overhaul_20261023` Phase 1, archived 2026-10-23).
- Grandchild pipe-descriptor hang on CLI kill: in native CLI wrappers (`_run_whisper_cpp`, `_run_audiocpp`), use bounded `proc.wait(timeout=0.05)` + reader `thread.join(timeout=0.5)` after `proc.kill()` rather than `proc.communicate()`, which blocks indefinitely if a grandchild process inherits stdout/stderr pipe descriptors (from: `asr_hardening_20261021` Task 2.2, archived 2026-10-23).

- Subprocess QML drivers built via textwrap.dedent: keep `\n` escapes literal inside nested strings/docstrings, and never let a line hit column 0 — dedent then no-ops into IndentationError in every subprocess (from: phase04_streaming_20260827, 2026-08-27).
- Subprocess GUI drivers using the REAL worker must call `shutdown()` before quitting — teardown aborts (rc=-6) otherwise (from: phase04_streaming_20260827, 2026-08-27).
- Hosts exposing ZERO audio output sinks (pipewire-less offscreen) make probe=False the DEFAULT path — playback-flow tests must inject `audio_probe=lambda: True`; assert the export-only posture explicitly rather than assuming device presence (from: phase04_streaming_20260827, 2026-08-27).
- Cancel-before-worker-pickup drains the queue silently and `busy` sticks True forever — await positive evidence of processing before cancelling in tests (from: phase04_streaming_20260827, 2026-08-27).
- Inside a NON-current hidden StackLayout tab offscreen, mid-session side effects (`historyCount`, edge-handler effects) may not run even though binding VALUES propagate — assert such state only while the tab is current/post-settled (extends the visibility rule above) (from: phase04_streaming_20260827, 2026-08-27).
- Qt SpinBox `displayText` renders through the HOST QLocale — the decimal separator follows system locale (`vi_VN` → comma) regardless of LANG; normalize separators before cross-machine string asserts (from: phase04_streaming_20260827, 2026-08-27).
- macOS reports `ru_maxrss` in BYTES (Linux: KB) — divide by 1024² for MB when comparing memory evidence across hosts; measure BOTH ru_maxrss and ps-sampled current RSS (from: phase04_streaming_20260827, 2026-08-27).
- `bd close --continue` AUTO-ADVANCES the next molecule step to in_progress — if premature, reset with `--status open`; real-model chunk counts vary run-to-run (codec adaptive buffering), never assert exact counts/timings against the live model (from: phase04_streaming_20260827, 2026-08-27).

- QML signal-handler parameters (`mouse`, `key`) are injected ONLY into the handler scope — a named helper called from the handler cannot see them (`ReferenceError: mouse is not defined` at click time, not load time, so the bug ships silently); write handlers as arrow functions with formal parameters (`onClicked: (mouse) => ...`) — Qt 6 deprecates implicit parameter injection anyway (from: bead-driven waveform work a6r/yi5/56h, 2026-08-29).

- SDK sample rates differ by function: `infer`/`infer_stream` → float32 mono @ 48 kHz; `denoise` → float32 mono @ **44.1 kHz** (from: phase01_core_20260827, 2026-08-27).
- `add_voice(save=True)` persists into **site-packages** by default — the app must redirect via `save_voices(path=<app data dir>)` (from: phase01_core_20260827, 2026-08-27).
- Qt cross-thread signals are queued to the receiver thread: tests/headless code must pump `QCoreApplication.processEvents()` while waiting (from: phase01_core_20260827, 2026-08-27).
- coverage.py cannot trace PySide6 QThread-run code (C++ threads) — keep logic in directly callable methods and test those synchronously (from: phase01_core_20260827, 2026-08-27).
- `Vieneu(backend="torch")` on a torch-free install raises `ModuleNotFoundError` — always surface an actionable "install [gpu] extra or switch to onnx" message (from: phase01_core_20260827, 2026-08-27).
- ONNX arena memory grows with the largest workload and is never returned to the OS. RESOLVED for streams (phase04): app-level chunked dispatch (`split_text_for_streaming`, 512-char segments via `infer_stream_chunked`) holds long-doc RSS at ~1.12 GB plateau vs <2 GB budget (AC-5, bead VieNeuTTSApp-u5c closed); interactive use stays ~766 MB. NON-stream path RESOLVED 2026-08-31 (bead VieNeuTTSApp-8jm closed): `_process_infer` no longer makes one whole-document `engine.infer` call — it dispatches `split_text_for_streaming` segments so each SDK call is bounded by the same mechanism (from: phase01_core_20260827, 2026-08-27; updated 2026-08-31).
- `sf.write` to an in-memory `BytesIO` needs explicit `format="WAV"`; and `TTSEngine.sample_rate`/`.backend` must raise before init — reading properties must never trigger the lazy model load (from: phase01_core_20260827, archived 2026-08-27).
- Docker Desktop image pulls can hang silently with no error output — compare `docker images` vs `docker ps` to distinguish pull-hang from container-run; kill early rather than waiting (from: phase01_core_20260827, archived 2026-08-27).
- PySide Slot return values: `@Slot(str, bool)` declares an OVERLOAD (str, bool), not a bool return — a QML one-arg call then fails with "Insufficient arguments". Returns are `@Slot(str, result=bool)` / `@Slot(str, result=str)` (from: phase03_corefeat_20260827, 2026-08-27).

## Performance evidence patterns

- Timing events use monotonic offsets from a trace start; distinguish direct
  engine TTFC, controller receipt, transport append, sink pull, and audible
  loopback latency.
- Record both sampled current RSS and monotonic peak RSS, with exact byte
  units at the API boundary.
- Benchmark records identify built-in corpus entries by ID and SHA-256 only;
  never serialize user text, voice names, paths, hostnames, usernames,
  serials, UUIDs, or environment variables.
- Run timing-sensitive suites serially. Keep raw JSONL samples and compare
  medians, p90/p95, and MAD instead of best-of-N results.
- Report direct-engine and production-path claims separately; unsupported
  frame, real-sink, and audible-TTFA metrics remain explicitly unsupported.
- Bench-gate every default: a knob ships at the SDK/library behaviour until a scripted `run_matrix` sweep on the executing host shows a win well outside the run-to-run range; a large effect from one sweep is re-confirmed in INTERLEAVED rounds before a flip, and each flip is its own commit (from: perf_hardening_20261009, 2026-10-09, Task 7.4; see `docs/performance/tuning-vieneu.md`).
- Bound a lazy-import refactor before writing it: time the app import with the module pre-imported vs not; the difference is the refactor's maximum win (numpy: ≤150 ms, below the 200 ms gate, so not done) (from: perf_hardening_20261009, 2026-10-09, Task 6.6).
- numpy per-call overhead (~10–20 µs on aarch64) dominates small-array DSP: count numpy calls per frame, not MACs — hoist frame-index-only work out of loops; a "cheaper" many-small-ops algorithm can lose to two FFTs (from: perf_hardening_20261009, 2026-10-09, Task 5.1).
- Keep the old implementation as a test oracle when vectorizing or rewriting a hot path (`tests/unit/wsola_reference.py`, the PCM codec loop); parity tests use short inputs because float32 near-ties can flip one pick on long ones (from: perf_hardening_20261009, 2026-10-09, Tasks 1.2/5.1).
- `app.aboutToQuit.connect(controller.shutdown)` binds the method AT CONNECT TIME — post-connect monkeypatches never fire; wrap before connecting in tests (from: phase03_corefeat_20260827, 2026-08-27).
- Document importer error surfaces vary by library and failure mode: pypdf raises different exception types per failure mode (catch broad + chain cause); python-docx raises `PackageNotFoundError`; `extract_text()` may return `None` — coerce with `or ""` (from: phase03_corefeat_20260827, 2026-08-27).
- `tests/fixtures/` is NOT covered by the ruff excludes — fixture generator scripts must pass lint/format like app code (from: phase03_corefeat_20260827, 2026-08-27).

- On-device ASR & Diarization pipeline discipline (`asr_hardening_20261021` + `VieNeuTTSApp-2ifr`, 2026-10-21): pin catalog model downloads by `size_bytes` and `sha256`, guard `remove_*_model` with `resolved.is_relative_to(models_dir)` + extension check, probe staged native CLI runtimes (`whisper-cli`, `audiocpp_cli`) with `--help` and `cwd=cli.parent` before atomic swap, separate `aiDownloadProgressChanged` ($\ge 1\%$ delta throttle) from `aiModelsInstallChanged` (start/finish/error only), share `source_16k.wav` (`source_16k.wav.json` sidecar) + `asr_segments_cache.json` + `diar_turns_cache.json` under `subtitles/_media_cache/<stem>_<hash8>/`, and disambiguate managed `.srt` files as `<stem>_<hash8>.srt` while keeping `project.title` set to the clean video stem.

- Deleting a possibly-real module from `sys.modules` in a test is a landmine: `monkeypatch.delitem(sys.modules, "torch")` let a second fresh `import torch` run in-process, whose C++ static registrations collided with the still-loaded first copy — every later `import torch` in that worker then died with `RuntimeError: Only a single TORCH_LIBRARY can be used to register the namespace triton` (it surfaced as unrelated `TestFrameLoop` failures in `test_qwen_host.py`). To simulate an absent module use `monkeypatch.setitem(sys.modules, name, None)`, which makes `import name` raise `ImportError` without touching the real extension (from: `5eb6f85`, 2026-10-21).
- Fake-host coverage of a subprocess engine (2026-09-21, `qwen_multiengine_20260920`): the scripted host logs only the frames it RECEIVED, so assert the ordered received list per host build, not "what we sent"; a crashed host's pid still answers `os.kill(pid, 0)` (zombie) until the engine's `close()`/`wait()` reaps it, so check reaping AFTER the close (and wait bounded before judging liveness); the host's pid is only public through its `starting` stderr line inside a 20-line tail, so read it right after `initialize()`; and a scenario that needs the RESTARTED host to behave differently must spawn the fake through a wrapper that reads its mode from a file, because the engine re-spawns the same command (from: commits 328baf5/9d52d1b, 2026-09-21).
- SIGPIPE belongs to the PROCESS, not the write (2026-09-21): `vienetts_app._restore_default_sigpipe()` sets `SIGPIPE` to `SIG_DFL` process-wide whenever the app's stdout is a pipe, so a plain `write()` to a dead child's stdin kills the whole app (observed as driver exit `-13`; pytest captures stdout with a pipe, a file-backed stdout hides it). Guard writes to a child pipe with `signal.pthread_sigmask` (block for the writing thread) + `signal.sigtimedwait` (consume a pending signal) and raise the actionable error instead — POSIX-only, gate on `hasattr(signal, "SIGPIPE")` (from: commit 328baf5, 2026-09-21).
- Second-controller e2e wiring: a flow that drives TWO controllers of the same kind (the audiobook sessions) must inject the SAME recording `PlaybackController` into both — the default factory builds a real `QMediaPlayer`, so the second session's resume-seek lands on an unobserved player and the assertion silently never fires (from: audiobook_epub_20260828, archived 2026-09-21).
- ggml `backend_init` is cwd/host-exe sensitive (from: qwen_gguf_engine_20260923 Task 1.1, 2026-09-23): with `GGML_BACKEND_DL=ON` it searches compile-time `GGML_BACKEND_DIR`, the *host executable's* directory, then *cwd* — never the `libqwen` directory. `dlopen` from another dir fails with `backend_init failed (no GGML backend available)`. The GGUF host subprocess must spawn with `cwd=<pack dir>` (recorded under `backendDiscovery` in `packaging/qwen-gguf-runtime-requirements.json`; verified on linux-x64-cpu).
- A missing GGUF `runtimeDir` is RUNTIME_INCOMPLETE, not `load_failed` (from: qwen_gguf_engine_20260923, 2026-09-24): it must carry `RUNTIME_INCOMPLETE_CODE` so the parent publishes a failed runtime card with Repair enabled (`_publish_runtime_failure`). Missing talker/codec files stay `load_failed` (model-side, fixed by another model/profile).
- Isolated host `main()` must `os._exit` after flushing pipes (from: qwen_gguf_engine_20260923 + multiengine, 2026-09-21…24): a daemon reader thread parked in a blocking `sys.stdin.buffer` read when `shutdown` wins the race makes interpreter finalization abort on `_enter_buffered_busy` (clean shutdown exits SIGABRT). `serve()` still returns normally so in-process tests are unaffected; `--qwen-host-check` keeps its normal return (no reader thread).
- Frozen PyInstaller JSON manifests need explicit data-file listing (from: qwen_gguf_engine_20260923, 2026-09-24): `collect_submodules` does not reach `Path(__file__).with_name("*.json")`, and a spec that only carries `ui/qml` + `ui/assets` cannot resolve ANY managed Qwen install (official OR GGUF) — every cell reports unshipped. Ship the manifests under `vienetts_app/core`.
- Multi-variant offline install needs a hardlink staging view (from: qwen_gguf_engine_20260923 Task 6.2, 2026-09-24): `install_offline` rejects a source carrying OTHER variants' files, so a provisioned all-variants model root must stage per-variant views with `os.link` (`copyfile` fallback) — never symlinks: the manager refuses symlinked candidates.
- Release evidence `emit` must gate on REQUIRED_SECTIONS presence, not just empty `problems` (from: qwen_gguf_engine_20260923 Task 6.2, 2026-09-24): an unrun/hand-built report can never exit 0. Skipped lifecycle checks (`--no-check-cancel`) are recorded as skip markers AND findings. Fake-host PCM is zeros — the WAV silence gate means a scripted fixture can NEVER mint a pass; pin that as a feature.
- GGUF cell claims distinguish PUBLISHED from PROBE-VERIFIED (from: refresh 2026-09-27, bead ysl8.7): four packs publish download recipes (`linux-x64-cpu`, `windows-x64-cpu`, `macos-arm64-cpu`, `macos-arm64-metal`) but only `linux-x64-cpu` has full four-variant probe evidence; `windows-x64-cuda`/`linux-x64-cuda` are unpublished. README/docs may name published packs; compatibility tables flip to `verified` only when all four variant probes pass (from: `docs/performance/qwen-gguf-compatibility.md` §6). **Stale-evidence rule (refresh 2026-10-07):** re-locking/re-publishing a pack at a new upstream pin invalidates ALL prior probe evidence for that cell — after the 2026-09-28 re-pin to `6fae9291`/ggml 0.25.3 every `verified` claim (including `linux-x64-cpu`'s §6 row, evidence from the `0cbde9b` packs) awaits a fresh per-cell smoke run; quote the pin beside any probe claim.
- Relocatable native packs (from: qwen_gguf_engine_20260923 Task 1.2, archived 2026-10-10): a CMake-built library carries an absolute build-tree RUNPATH — staging must rewrite it (`patchelf --set-rpath '$ORIGIN'` on Linux, `install_name_tool -add_rpath @loader_path` on macOS) and prove it with `ldd` from a foreign cwd. The glibc floor is the BUILD HOST's toolchain, not the runner label: measure it from the shipped binaries (`glibc_floor` → `BUILD-INFO.measuredGlibcFloor`) and build on the oldest supported distro (ubuntu-22.04 → 2.35). Bundle `libgomp.so.1` with its GCC Runtime Library Exception copyright rather than flooring it.
- ctypes boundary rules (from: qwen_gguf_engine_20260923 Task 4.1, archived 2026-10-10): keep every callback object (chunk/cancel/log) referenced for the WHOLE native call; copy borrowed buffers inside the callback before it returns; never let a Python exception cross the boundary — the relay captures it, returns a stop verdict, and the caller re-raises after the native call returns; native frees are NULL-safe and run on every path, early validation exits included. Silence the library's stdout before init when the host speaks a pipe protocol.
- Content-verified installs (from: qwen_gguf_engine_20260923 Task 3.1/3.2, archived 2026-10-10): pin each model file by path, size+SHA-256 AND the metadata its header must declare (GGUF KV: architecture, file_type, …), so bytes that match but a header that lies still fail. Parse only the header through a `read(n)` seam with bounds on counts and string/array sizes, stopping once every wanted key is seen. Never trust links inside a downloaded archive — extract regular members only and recreate links from the lock. Refuse another platform's pack before any disk work (it verifies byte-perfect but can't load), and keep `status()` digest-only so it is GUI-thread safe.
- `scripts/benchmarks/` changes need `pytest -m benchmark` too: the perf-harness smoke tests are `benchmark`-marked and the default `-m 'not benchmark'` gate skips them — a `run_engine` trace tag outside `PerformanceRecorder`'s `SAFE_TAG_KEYS` broke every direct run with the gate green (from: perf_hardening_20261009, 2026-10-09, Task 7.4).
