## ⚡ VieNeuTTS v0.1.1 — Performance & Polish

A patch release focused on **speed, responsiveness, and cross-platform polish** for [VieNeuTTS](https://github.com/NguyenSiTrung/VieNeuTTSApp) — the fully on-device Vietnamese/English text-to-speech desktop app powered by [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo).

All text and audio processing still run 100% locally — private, offline, no telemetry, no cloud.

---

### ✨ What's New

- **🚀 Faster startup & smoother UI**:
  - Heavy imports are deferred and engine prewarming starts right after the first paint — the window appears noticeably sooner.
  - Heavy tabs (audiobook, voice cloning) load lazily; the karaoke reader now only re-parses the active paragraph instead of the whole chapter.
  - Window size and position are remembered between launches.
- **🎧 Smoother streaming playback**:
  - Zero-copy audio chunk handling and smarter buffer growth reduce glitches on long texts.
  - Level metering is paced off the audio thread; chapter saving, EPUB opening, and document import/export moved to background workers so the interface never freezes.
- **📚 Audiobook studio: selectable transcript & one-tap chapter copy**:
  - Reader paragraphs are now selectable — drag to select text, `Cmd/Ctrl+C` to copy. Tapping still seeks, and keyboard shortcuts are unchanged.
  - New **Sao chép chương / Copy chapter** button copies the entire chapter transcript to the clipboard in one tap.
- **🖥️ Platform polish**:
  - **Windows**: proper taskbar identity (AppUserModelID), dark-mode titlebar, robust audio export when files are locked by other apps, exports default to your Music folder.
  - **Linux**: the release zip now ships a desktop entry, hicolor icons, and an `install.sh` for one-command menu integration; audio playback in the packaged app is fixed (GStreamer bundled via CI).
  - **All platforms**: audio device errors now surface as a translated banner instead of silent failure; `Ctrl+C` in a terminal quits cleanly; clearer guidance for Intel Macs (build is Apple Silicon–only).

### 💡 Notes for First-Time Users

1. **Model Weights (~750 MB)**:
   The neural network weights are **not bundled** in the installer to keep download sizes reasonable. On your first synthesis, the app will automatically download the required model files from Hugging Face into the local cache.
2. **macOS Gatekeeper**:
   Because the macOS build is ad-hoc signed, macOS may prompt on first launch. Right-click `VieNeuTTS.app` → click **Open** → click **Open**, or run:
   ```bash
   xattr -dr com.apple.quarantine /Applications/VieNeuTTS.app
   ```
3. **Linux Prerequisites**:
   Ensure basic Qt6 runtime libraries are present:
   ```bash
   sudo apt install libasound2 libpulse0 libgl1 libegl1 libxkbcommon0
   ```
