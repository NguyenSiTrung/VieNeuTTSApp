## Learnings Extracted This Section

### Patterns discovered
- QIODevice subclasses come from PySide6.QtCore — ring-buffer push devices need no QtMultimedia import; "format factory returning a configured object" keeps fakes trivial.
- huggingface_hub `LocalEntryNotFoundError` MRO = FileNotFoundError→OSError→EntryNotFoundError; `OfflineModeIsEnabled` is a ConnectionError — classify by walking the exception chain, not message text.
- Real-model stream chunk counts vary run-to-run (codec adaptive buffering) — never assert exact chunk counts against the live model.
- Offscreen smoke e2e pattern matured: REAL controller/worker/QML over SDK-layer fakes works for streaming too (see `TestTextStreamE2E` in test_ui_tabs.py).

### Gotchas encountered
- QML var-property signals don't fire on in-place array mutation — REASSIGN the array.
- Hidden StackLayout tabs defer `visible` binding updates offscreen — setCurrentTab before asserting visibility.
- Cancel-before-worker-pickup drains the queue silently and `busy` sticks True forever — await evidence of processing before cancelling.
- This host exposes ZERO pipewire output devices: probe-False is the DEFAULT path here; playback-flow tests must inject `audio_probe=lambda: True`.
- Initial QML binding evaluation happens during engine.load(); subprocess GUI drivers using the REAL worker must call shutdown() or rc=-6.
- textwrap.dedent drivers: escape `\n` and docstrings inside nested strings; a zero-indent line no-ops dedent into IndentationError in every subprocess.
- bd close --continue AUTO-ADVANCES the next molecule step to in_progress — reset with `--status open` if premature (bit us twice).
