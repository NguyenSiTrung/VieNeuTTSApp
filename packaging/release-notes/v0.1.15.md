## VieNeuTTS v0.1.15 — SRT Subtitle Studio, Studio Pinned Transport & Workflow Redesign

This release introduces a timestamp-aware Subtitle (SRT) Dubbing & Transcript Studio,
a comprehensive redesign of the Audio Studio tab around a pinned transport and truthful
state, a 3-mode segmented Paragraph Studio with docked controls, restructured Settings
cards with 64-bit platform hardening, and significant test suite performance optimizations.

### Added

- **Timestamp-Aware Subtitle (SRT) Dubbing & Transcript Studio:**
  - Dedicated "Phụ đề (SRT)" / "Subtitles (SRT)" mode composed into the Paragraph Tab
    (`SubtitleCard.qml` backed by `SubtitleController`).
  - **Cue-Aligned Dubbing Mode (`dub`):** Timecode-constrained synthesis aligning spoken
    dialogue with exact SRT subtitle cues using WSOLA time-stretching within natural speech
    bounds and automatic inter-cue silence padding.
  - **Natural Transcript Mode (`transcript`):** Groups subtitle cues across sentence
    boundaries (bounded by `UNIT_MAX_CHARS` and `UNIT_GAP_MS` guards) for continuous, natural
    narration without robotic cue-by-cue pauses.
  - **Streaming Track Render & Smart Caching:** Clip-by-clip streaming render directly to
    `PCM_16` `track.wav` (keeping RAM usage under ~690 MB vs ~1.4 GB in RAM for 2-hour tracks)
    with SHA-256 fingerprint caching that reuses cached audio when text, voice, or timing are unchanged.
  - **Synchronized Subtitle Playback:** Live playhead tracking across subtitle cues with active
    cue highlighting and interactive waveform seeking.
  - **Flexible Subtitle Export:** Export aligned full-mix audio (WAV or MP3), adjusted SRT
    subtitle files with updated timestamps, or natural transcript text.
  - **Full Bilingual Localization:** 100% Vietnamese and English localization across all subtitle
    studio cards, dialogs, badges, and status messages.

- **Audio Studio Redesign (Pinned Transport & Waveform Selection):**
  - **Pinned Transport Dock:** Audio transport dock is permanently pinned to the bottom of the
    Studio tab so Play/Pause/Seek, timecodes, and preview buttons remain accessible regardless
    of vertical scroll.
  - **Master Waveform Region Selection:** Interactive click-and-drag range selection on the 72px
    master waveform deck with one-click actions to Keep (`TrimOp`) or Delete (`CutOp`) regions.
  - **Truthful Dynamic Op Stack:** Operation rack readouts fold mathematical transformations in
    real time (gain sums, speed multiplies) to match the rendered output; applying adjustments
    updates parameters in place without stacking redundant duplicate operations.
  - **Truthful Clip Auditioning:** Auditioning an individual clip publishes its specific ID,
    duration, and waveform envelope so the transport dock, timecode, and highlighted row reflect
    the clip actually playing.
  - **Clickable Op-History Breadcrumbs:** Interactive timeline chips (`studioRevertTo`) allow
    instantaneous rollback to any prior operation in the history chain.
  - **Keyboard Transport & Shortcuts:** Spacebar toggles Play/Pause, Escape halts playback, and
    arrow keys provide stepped waveform navigation when the Studio tab is active.
  - **Quick Actions:** Per-clip deletion controls and quick export shortcut.

- **Paragraph Tab Redesign & Mode Composition:**
  - **Segmented 3-Mode Architecture:** Refactored monolithic 948px scrolling tab into three
    dedicated views via a segmented `ModeTabs` control: "Một tài liệu" (`DocumentEditorCard`),
    "Nhiều tệp" (`BatchQueueCard`), and "Phụ đề (SRT)" (`SubtitleCard`).
  - **Docked Synthesis Action Bar:** Docked bottom `SynthesisBar` keeps Voice picker, Generate,
    Play, Export, and Run-all actions permanently visible with responsive Flow wrapping for
    compact window widths.
  - **Stationary Navigation:** Stabilized layout geometry, fixed scrollbar jitter, and eliminated
    mode-switch slack so the page header and mode selector remain stationary when toggling modes.
  - **Batch Queue Clarity:** Dedicated batch drop zone and clear visual error reporting for queue failures.
  - **VoicePicker Regional & Bilingual Disambiguation:** Disambiguates regional accents ("Miền Bắc",
    "Miền Trung", "Miền Nam", avoiding duplicate "Nam" chips for southern male voices) with complete
    English catalog localization.

### Fixed & Improved

- **Settings Tab Restructure & Hardening:**
  - **Modular Card Layout:** Split monolithic 801px Engine card into three clean cards: Engine
    (backend, precision, detector), Managed CUDA Runtime (status, storage metrics, copyable driver
    commands), and Model Source (official vs custom Hugging Face model).
  - **Auto-Expanding CUDA Diagnostics:** Troubleshooting disclosure stays collapsed by default and
    automatically expands when an installation is in flight, failed, or driver action is needed.
  - **64-Bit Byte Count Overflow Fix:** Widened `modelInstalledBytes`, `modelRequiredBytes`,
    `cudaRuntimeInstalledBytes`, and `cudaRuntimeRequiredBytes` from 32-bit `int` to `qlonglong`,
    preventing `OverflowError` crashes on 64-bit systems inspecting multi-GB CUDA runtimes.
  - **Deterministic QML Teardown:** Added `_teardown_qml()` on application exit, ensuring Qt
    context properties remain alive until tear-down finishes and eliminating ~190 spurious
    `TypeError: Cannot read property 'x' of null` shutdown errors.

- **Audio & Platform Reliability:**
  - **Windows Soundfile Lock on Abort:** Explicitly released underlying soundfile handle during
    synthesis cancellation/abort, preventing `WinError 32` file locking and allowing temporary
    WAV files to be cleanly unlinked on Windows.
  - **Studio Delegate & Contrast Fixes:** Resolved QML Repeater delegate instantiation bug on
    op-stack chips and improved text contrast on `accentSubtle` chips; tuned `Theme.waveformIdle`
    to >=3:1 contrast on both dark and light themes.
  - **Responsive Scaling:** Guaranteed UI integrity down to 640x420 minimum window dimensions
    without slider collapse, horizontal overflow, or nested ScrollView wheel traps.

- **Performance & Documentation:**
  - **Test Suite Runtime Optimization:** Consolidated duplicate micro-tests and folded repetitive
    smoke scenarios, reducing full-suite runtime by ~30% with 100% assertion retention (suite
    expanded to 1,055 items).
  - **Documentation & Asset Refresh:** Updated `README.md` with Audio Studio, MP3 export, and
    Paragraph batch queue documentation, and regenerated all 6 application screenshots.
